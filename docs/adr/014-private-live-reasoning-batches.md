# ADR 014 — Label-free provider batches with one spending ledger

Date: October 15, 2026. Status: offline integration verified; live credentials, model/region choice and spending approval pending.

CHAOSLAB exports a private input manifest containing canonical source inputs, their hashes and opaque case identifiers. Expected labels and descriptive diagnostic case names are excluded. ATLAS consumes that JSON contract without importing the judge. Each exported case is schema/size/identity-validated before provider initialization. Results retain input identity and complete source snapshots.

The new model benchmark CLI defaults to a local reservation plan, which never opens a provider client or resolves credentials. Execution requires explicit `--allow-paid`. One Bedrock gateway and its conservative ledger cover every selected case; there is no per-case budget reset. The default selects one smoke case. Any failure stops subsequent cases, including ambiguous invocation/billing failures. Reservations are journaled before inference; artifacts remain under ignored `var/`, mode 600. Existing or interrupted invocation artifacts cannot be silently reused. Failed client initialization can leave a reservation requiring a new output name; it does not authorize a retry.

The plan describes a maximum reservation under configured model token prices, not an AWS account-wide spending cap or invoice. Provider compatibility, token accounting, regional/inference-profile prices and external fees require review. Live gateway opening now rejects nonpositive base prices, an unofficial pricing-page identity, and price-card verification dates outside the preceding seven days. These are mechanical admission checks, not proof that a human-entered price is correct. Synthetic test prices remain usable only with explicitly constructed offline gateways and dry plans.

Artifact scoring binds the dataset identity, opaque case identity, canonical input hashes and returned document snapshots to the independent authored labels. Duplicate/unknown cases or changed inputs refuse scoring. A partial smoke run reports evaluated and not-run case counts; unrun cases are excluded from semantic-quality denominators. Failed recorded cases remain errors, so the result is an operational end-to-end score, not a pure estimate of model reasoning ability. Artifacts are trusted local records, not signed provider attestations. Scores stay private and never overwrite the public baseline automatically.

Ten new offline tests use real boto3 protocol stubs to execute the model workflow, exercise shared receipts and unknown charges, verify private artifact scoring, reject identity mismatches, and prove default planning does not touch provider credentials. They are integration/contract evidence only; no live model quality or actual AWS charge is measured.
