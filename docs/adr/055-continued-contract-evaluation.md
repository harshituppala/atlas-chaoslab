# Continue a stopped evaluation without repeating the saved prefix

The development evaluation stopped after twenty-three documents. Restarting the whole split would pay for those documents again and discard a useful recovery boundary. The read-only checkpoint audit already admits their inputs, output shapes and usage receipts; it does not prove the answers are correct or authenticate them with the provider.

A separate continuation command now creates a new run. It reads the admitted prefix unchanged, submits only the remaining ordered inputs to the model and writes a new complete observation journal. The independent judge scores every document, including saved wrong answers. The original journal, usage ledger and full campaign reservation stay intact. There is no automatic retry, refund or in-place repair.

The new campaign reservation covers only the missing calls at the newly reviewed price. Model identity, region and input/output limits must match the original receipts; existing operator limits must fund the tail before the configuration is narrowed. Input hashes reject reordered or changed requests. Origin files are checked before and after each adapter call; an integrity failure escapes the judge's ordinary wrong-answer handling and stops publication. An interrupted continuation stays incomplete and is not automatically continued again.

Aggregate export requires the original checkpoint and campaign ledger as well as the new complete run. It checks the copied answers against the original, retains both reservations, reconciles new receipts separately and independently replays all observations. The report distinguishes new-call usage and timing from saved-prefix usage. It describes an assembled development result, never an uninterrupted run or untouched-test accuracy.

Controlled SDK tests cover one new call for the missing document, unchanged wrong predictions, replay equality, altered source files, mismatched model limits, unavailable spending capacity, provider interruption and missing export lineage/reservations. The actual private dry plan admits twenty-three saved documents and thirty-eight missing documents. These checks make no provider request and establish no new model accuracy. The original response bytes remain unauthenticated; local file ownership and checksums are evidence controls, not an adversarial-host security boundary.
