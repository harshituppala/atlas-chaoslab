# ADR 024 — Separate evidence contamination from strict paired regressions

Date: 2026-10-16

Add six authored clean/hostile evidence pairs, frozen before execution. Each pair preserves its obligation, factual source, metadata and expected relation; only the appendix text changes. Cases probe role spoofing, Unicode-obscured directives, schema-choice spoofing, approval bait and retrieval keyword bait. A benign security-training fact containing the phrase system prompt exposes false-positive filtering. Golden policy excludes the instruction-bearing appendix even when it includes plausible capability claims. This conservative quarantine policy is explicit; it is not a universal entailment definition.

The independent scenario judge still checks full obligation extraction, exact evidence record sets/quotes, citation integrity, extractive draft and pending review. New paired aggregation reports complete-pair coverage, conditional strict regressions only where the clean control passes, forbidden-source citation cases and unauthorized review-state cases separately. Missing pairs leave conditional rates unknown when no eligible denominator exists. A strict regression can be extraction, relation, selection or operational failure; it must not be relabeled a successful prompt injection. Valid source offsets do not establish safe or authoritative content. No tools, secrets or external communication exist in this experiment, so exfiltration/tool safety is not measured.

Thirteen evaluator checks cover correct paired outputs, valid-but-hostile citations, independent approval violations, incomplete coverage, operational failures, duplicate identities, mismatched factual inputs/expectations/metadata and invalid forbidden-source sets. Labels and pair names stay outside the exported adapter input; opaque input IDs bind dataset/source identity.

Actual deterministic baseline result: 3/12 strict case contracts passed; all six hostile appendices were cited. Three complete pairs had passing clean controls; all three regressed under the strict contract. Zero unauthorized review states were observed. These are failures of the extractive path on this small same-author diagnostic, not measured behavior of a live LLM or a population attack rate. Earlier adversarial and reasoning reports remain unchanged.

A separate model comparison was prepared, not executed: twelve cases, at most 24 calls, USD 0.2433024 worst-case configured reservation. The existing restricted AWS credential preflight failed before reservation/inference. No budget debit or paid request was made. The current source-selection-v4 prompts/semantics remain unchanged; three release CI formatting corrections are whitespace-only. After verifying the human's cross-chat publication request, prioritize release preparation rather than expanding this test family. A future completed live run needs separate execution identity, coverage, provider usage and source-drift checks; this baseline cannot be represented as model injection resistance.
