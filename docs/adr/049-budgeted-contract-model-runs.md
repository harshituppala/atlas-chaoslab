# Keep contract inference separate from its judge

The external contract task needed a real model adapter, but its evaluator should not acquire an AWS dependency or borrow the application's decision logic. The integration therefore sits in `atlas.models.contract_evaluation`. CHAOSLAB still owns the input boundary, authored labels, observation admission and scoring. The separately installed evaluator remains usable without ATLAS or a model SDK.

The bridge admits only the document, candidate spans and fixed claim text. It rejects extra annotation or instruction fields before any provider request. It gives the model the complete contract and numbered evidence excerpts, with an application-owned system instruction. Dynamic output schemas restrict claim identities and choices. Local scoring still checks duplicate predictions, evidence bounds, omissions and wrong answers. A correctly shaped answer is not a correct assessment, and prompt construction is not proof of injection resistance.

One gateway and ledger cover the complete development split. The operator first gets an offline plan that checks every prompt and full-split call capacity. Live mode requires a new private run directory, current price admission and a retained campaign reservation before provider setup. It reuses the existing no-retry SDK policy and durable receipt callbacks rather than introducing another spending counter.

Completed but unusable model responses count as failed documents. Their usage remains recorded; rejected provider bodies are not copied into reports. Provider or usage uncertainty stops the cohort. Failed recording, exhausted limits or source changes also stop publication. A stopped prefix cannot become a complete-split accuracy score. The partial observations and receipts remain private for diagnosis; a fresh attempt does not overwrite them or automatically refund their reservation.

The first live attempt stopped during preflight after eighteen validated responses. Its known inference estimate was $0.1964666, with the full $2.984608 campaign reservation retained. A later token-count-only probe of the next input succeeded. The original service error code was not retained, so its cause remains unconfirmed. A fresh attempt with ten-second request spacing also stopped during preflight, after twenty-three validated responses. Its known inference estimate was $0.2406261. Both prefixes overlap; they are not forty-one distinct contracts. A probe of the next input again succeeded. Pacing did not eliminate the interruption, and neither cause is confirmed. Further inference is paused; both full reservations remain retained. See the [stopped-run record](../../reports/contract-model-stopped.json).

Before any complete model result is exported, a separate recorder admits the saved run and all observations, checks the source/data identity, rescores every response and reconciles token-price arithmetic. It also computes the constant-label reference under the same scorer and inputs. Only aggregate scores and receipt fingerprints leave the private run directory. These checks catch inconsistent local evidence; they cannot authenticate an operator-controlled file or turn SDK receipts into signed provider attestations.

Thirty-five adapter controls and eight export controls passed using fictional contracts and SDK stubs. The native suite passed 772 tests, with eighteen optional PostgreSQL groups skipped. They cover label-free requests, malformed and wrong answers, whole-cohort stopping, retained private receipts, recording/source failure, pacing, offline admission and export reconciliation. These are implementation controls, not evidence of model quality. The [runbook](../contract-model-runbook.md) explains access, spending and replay.
