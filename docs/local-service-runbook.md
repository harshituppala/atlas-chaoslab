# Local API and worker lifecycle

This optional profile starts the API and one baseline worker together on the local machine. It prepares a simpler runtime for future hosting work; it is not safe to expose as an anonymous public service. The usual separate API and worker commands remain available.

Use a dedicated database, not another running service's file. From the repository root, with the existing private var/local-credentials.json generated by the local demo setup:

```sh
PYTHONPATH=src .runtime/bin/python -m atlas.local_service \
  --database var/local-service/atlas.db \
  --credentials var/local-credentials.json \
  --port 8132
```

The credentials file must not grant group/other access. Do not print or commit its contents. Configure the local workbench to use http://127.0.0.1:8132 and the existing local token. The launcher refuses ATLAS_DATABASE_URL, ATLAS_MODEL_JOB_SPEC, ATLAS_ENABLE_BEDROCK_JOBS or ATLAS_TOKEN_TRUST when set. Run this profile in a clean shell rather than mixing model/managed-service settings into it. Existing model jobs in the selected database are not claimed by this baseline worker.

Readiness is /readyz. It returns 503 if the worker stops or fails, even while /healthz remains 200. A loop failure requires operator investigation and a fresh process; requests can still enqueue durable jobs while readiness is failing. Health endpoints intentionally omit exception/database/source details. Do not configure a future host to equate liveness with the ability to process jobs.

Use a normal interrupt or SIGTERM to stop. Shutdown waits for an entered queue step, then closes both engines. The child has a ten-second computation deadline; database and publication time are additional. A thirty-second thread join failure is an error, not a forced kill or proven cleanup. If the host kills the process, unfinished jobs rely on the existing lease recovery rules. A free host losing its local filesystem would lose this database; the local restart check does not solve that problem.

## Repeat the checks without inference

```sh
mkdir -p var
PYTHONPATH=src .runtime/bin/python -m pytest -q \
  --basetemp=var/local-service-confirm \
  --junitxml=var/local-service-tests.xml
PYTHONPATH=src .runtime/bin/python scripts/verify_local_service.py
```

The recorder requires the nine lifecycle cases and a passing supplied regression artifact, then runs real loopback HTTP against a fresh private synthetic database, restarts the service and checks the unchanged result. Temporary credentials and logs remain inside ignored var and are removed with the test directory. The public report contains counts/status codes and source/test hashes, not credentials, raw inputs or exception text. Its source identity is checked before/after the HTTP exercise; JUnit/test-source hashes are captured after testing and do not attest loaded code.

reports/local-service.json records the latest successful execution. ADR 031 also records the initial non-reproduced queue test failure and the recorder's corrected Uvicorn signal assumption. No paid call or deployment is part of these commands. Public-session isolation, bounded anonymous sessions/cleanup, free-host durability and explicit publication remain separate unfinished gates.
