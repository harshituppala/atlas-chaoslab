# ADR 013 — Separate source identity from factual support

Date: October 15, 2026. Status: implemented; deterministic baseline executed.

The retrieval fixtures measure finding a relevant document, and citation validation measures source identity. Neither establishes that the evidence satisfies every condition of an obligation. CHAOSLAB now has an independently scored 18-case diagnostic set with authored supported/contradicted/insufficient labels. It covers exact support, residency conflicts and backup exceptions, recovery thresholds and aspirations, retention duration, negation scope, roadmap timing, conjunctive encryption requirements, incident coverage, irrelevant evidence and paraphrased obligation extraction.

Labels were written before running this evaluation. The cases deliberately target known classes of heuristic weakness; this is not a blinded holdout, random sample, unbiased model comparison or a production accuracy estimate. Keep the source fixtures and labels versioned. Do not modify expected labels to improve a score. A later blinded dataset and human adjudication are needed for stronger quality claims.

Adapters receive only document inputs, without labels, through the existing deadline/byte-bounded trusted process protocol. The judge imports no ATLAS validation helpers. It reconstructs source hashes and exact spans from the original case, checks requirement/knowledge scope, and rejects agent approvals and unsupported draft text. Its conservative positive-reference contract requires citing the whole authored capability record; a valid shorter citation does not automatically satisfy that contract. This is a reference policy for these small records, not a universal rule for document RAG.

An absent obligation is recorded as omitted, not insufficient evidence. Duplicate/wrong extraction is a distinct invalid-extraction outcome. Adapter exceptions are type-only error records. The confusion matrix keeps these failures in the end-to-end denominator. Relation-label accuracy, extraction coverage, supported-label precision and insufficient-label recall are separate from the full grounding/review contract pass rate. Zero denominators remain unknown. A correct relation label with invalid citations can match the label metric while failing the grounding contract; do not conflate those metrics with arbitrary claim-level faithfulness.

Actual baseline results: 10/18 full-contract cases passed; exact extraction coverage 17/18; relation accuracy 10/18; supported precision 5/10; insufficient recall 1/4. Eight failures remain explicit regression cases. The evaluator has ten local regression/mutation tests including forged hashes, foreign/self evidence, premature approvals, unsupported prose, incomplete reference spans, duplicate/omitted extraction and empty metric denominators. No live LLM was invoked and no generative hallucination rate or legal-compliance accuracy is claimed.

The workbench shows the measured confusion matrix and all labelled case outcomes. CI is configured to regenerate the report, but remote CI execution remains unvalidated. A future provider-backed adapter must preserve explicit spending approval, private source-bearing usage journals and actual provider identity/accounting evidence. This milestone neither enables paid execution nor claims that the production model path is integrated.
